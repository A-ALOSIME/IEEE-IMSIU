# معايير التنفيذ

- حفظ دائم في D1؛ لا بيانات تجريبية أو صلاحيات يختارها المستخدم في نسخة الإنتاج.
- Cloudflare Access JWT مُتحقق منه، والأدوار على الخادم، والنماذج العامة عبر Turnstile.
- لا مفاتيح أو ملفات شخصية عامة؛ مرفقات R2 محمية.
- معاملات ذرية للقبول الجماعي والساعات، ومنع التكرار وتعارض الكتابة.
- التصميم المعتمد وأرقام 0–9 وRTL/LTR والجوال والوضعين.
- نجاح الحفظ والبريد يعكس استجابة الخدمة الفعلية، بلا محاكاة.
- الفحص والاختبارات والبناء ومراجعة الاعتماديات قبل رفع الفرع؛ لا تخفيض للاختبارات لتجاوز خطأ.
